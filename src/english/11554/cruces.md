# Cruces — 11554 (Richard of St Victor, Quomodo Christus ponitur in signum populorum)

## Col 0523B/C (chunk 0000) — garbled type in the Psalm quotation
- **Reading (as printed):** `*Et adorabunt cum omnes reges, [0523C] omnes gentes servient ei*`
- **Note:** `cum` stands where the sense and the source (Ps. 71:11, *adorabunt eum omnes reges*) require *eum* ("him") — the direct object of `adorabunt`, parallel to the following `servient ei`. A plain misprint (c/e confusion). Rendered per the intended object ("And all kings shall adore him"); the Latin itself is not emended.
