# GLOSSARY — Maximus the Confessor, *Epistulae* 1–45 (PG 91.364–649): one term, one rendering, the whole work

Seeded 2026-11-06 (Fable) from the Letter 1 anchor, a census of every technical form in the 28 scaffolds (55,000 Greek
words), and the rulings already standing in `translation-style.md` (οὐσία = essence · φύσις = nature · ὑπόστασις =
hypostasis · πρόσωπον = person · ἐνέργεια = operation · θέλημα = will / θέλησις = volition are **binding corpus rules**;
the whole first table of `translate/sophronius-orationes/GLOSSARY.md` is inherited, because the dogmatic letters (12,
13, 14, 15, 19) argue the same controversy in the same words). A term not listed: choose one rendering, keep it, and name
it in your report (Greek → English, one line). Briefs run in parallel, so clashes are swept after the run.

## II. Maximus's own vocabulary — fixed here (2026-11-06)

| Greek | English | why / note |
|---|---|---|
| γνώμη (65) | inclination | the scholarship's "gnomic will". Kept apart from διάθεσις (disposition), θέλησις (volition), βούλησις (wish), κρίσις (judgement); γνωμικός = of inclination, γνωμικῶς = by inclination; never "opinion", "mind", "judgement". (The Sophronius glossary's forecast "judgement" is superseded; κρίσις needs that word here.) |
| διάθεσις (31) | disposition | ἐνδιάθετος = inward |
| ἕξις (9) | habit | ἕξις τῆς ἀρετῆς = habit of virtue; θεωτικὴ ἕξις = deifying habit |
| σχέσις (33) | relation | the ascetic sense too ("relation to the senses", Letter 2): one word, the reader sees the technical term; σχετικός = relational |
| κίνησις (27) / στάσις | movement / rest | the Maximian triad γένεσις – κίνησις – στάσις = coming-to-be, movement, rest; ἀκίνητος = unmoved; ἀεικινησία = ever-moving |
| λόγος (613) | principle · reason · word · account (by sense) | ὁ λόγος τῆς φύσεως / τοῦ εἶναι = the principle of nature / of being; οἱ λόγοι τῶν ὄντων = the principles of beings; λόγος alone = reason where it is the faculty, word/speech where it is utterance, account where it is an argument ("ὡς ὁ ἐμὸς ἔχει λόγος" = so my account has it). The λόγος–τρόπος pair = **principle and mode**, always |
| τρόπος (138) | mode (technical) · manner (ethical) | τρόπος ὑπάρξεως = mode of existence; τρόπος τῆς ἑνώσεως = mode of union; but "the gentleness of thy manner" (anchor) |
| μοναδικός (≈30) | singular | Letters 12–13 against Severus: a nature is either γενική (generic) or μοναδική (singular, of one individual); τὸ μοναδικόν = singleness; NOT "monadic" (μονάς = Monad is the Trinity's word) |
| γένος / εἶδος / ἄτομον | genus / species / individual | the Porphyrian ladder of Letters 12–15; εἶδος = form only where no species is in view |
| ὑποκείμενον | subject | Aristotle's substrate; "the stone in its subject" (Letter 12) |
| ποιότης (50) / ποσόν | quality / quantity | |
| ἀριθμός (74) | number | Letter 12's argument that number does not divide; ἀριθμεῖν = count |
| θέωσις (10) | deification | θεωτικός = deifying; θεοῦσθαι = be deified |
| ἀγάπη (120) | love | ἀγαπᾶν = love; Letter 2 is "on love" |
| ἔρως | yearning | the soul's ἔρως bound to matter (anchor); ἐραστής = lover |
| πόθος / ποθεῖν | longing / long for | |
| ἔφεσις (6) | aspiration | the upward reach of desire; kept apart from ἐπιθυμία |
| ἐπιθυμία (24) / θυμός (17) | desire / anger | the two irrational powers; τὸ ἐπιθυμητικόν = the desiring power, τὸ θυμικόν = the incensive power, τὸ λογιστικόν = the rational power |
| ὄρεξις (5) | appetite | ὀρεκτικός = appetitive |
| ἡδονή (13) / ὀδύνη (11) | pleasure / pain | the Maximian pair; λύπη = grief |
| ἀπάθεια (16) | dispassion | ἀπαθής = dispassionate (of men) / impassible (of God and of Christ's Godhead) |
| φιλαυτία (10) | self-love | |
| ἀρετή (94) / κακία (26) | virtue / vice | τὸ κακόν = evil; πονηρία = wickedness |
| πρᾶξις (30) / θεωρία (14) / γνῶσις (52) | practice / contemplation / knowledge | the ascetic triad; πρακτικός = practical; θεωρητικός = contemplative; γνωστικός = of knowledge |
| νοῦς (41) | mind | νοερός = intellectual; νοητός = intelligible; διάνοια = understanding |
| λογισμός (17) | thought | the ascetic "thoughts" (λογισμοί) |
| πρόνοια (15) / κρίσις (13) | providence / judgement | the Evagrian pair, "the principle of providence and judgement" |
| ἐντολή (40) | commandment | |
| ταπείνωσις / ταπεινός | humility / lowly | "we the lowly" is Maximus's self-styling; ταπεινοφροσύνη = humble-mindedness |
| φιλοσοφία | philosophy | the ascetic life (T note once per letter where it first means that) |
| μυστήριον (44) | mystery | |
| χάρις (106) | grace | χάρισμα = gift of grace |
| ἄκρον / μέσον | extreme / middle | Letters 12–13: the two natures as "extremes" (ἄκρα) of the composite |
| συστολή / διαστολή | contraction / expansion | |
