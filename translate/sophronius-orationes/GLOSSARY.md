# GLOSSARY — Sophronius of Jerusalem, Synodical Letter + Orationes II, IV, V, VII, VIII (one term, one rendering, the whole work)

Seeded 2026-11-05 (Fable) from the two anchors, a census of every technical form in the eighteen scaffolds,
and the rulings already standing in `translation-style.md` (οὐσία = essence · φύσις = nature · ὑπόστασις =
hypostasis · πρόσωπον = person are **binding corpus rules**, not choices made here). A term not listed: choose
one rendering, keep it, and name it in your report (Greek → English, one line). Briefs run in parallel, so
clashes are swept after the run. **The Christological table is held constant across all eighteen chunks — the
Letter's argument is made of these words, and a synonym is an error.**

## Trinity and Christology — the fixed vocabulary

| Greek | English | why / note |
|---|---|---|
| οὐσία | essence | corpus rule; οὐσιώδης = essential, οὐσιωδῶς = essentially; ὑπερούσιος = superessential |
| φύσις | nature | corpus rule; φυσικός = natural, φυσικῶς = naturally, κατὰ φύσιν = according to nature |
| ὑπόστασις | hypostasis | corpus rule (kept, not "subsistence": the Letter opposes it to πρόσωπον and φύσις at once, and only the Greek word holds the three apart); pl. hypostases; ὑποστατικός = hypostatic; ἐνυπόστατος = enhypostatic (T note once) |
| πρόσωπον | person | corpus rule; προσωπικός = personal; "face" only where a literal face is meant |
| θεότης | Godhead | never "divinity" (θειότης, if met, = divinity) |
| ἀνθρωπότης | manhood | the Chalcedonian pair Godhead / manhood |
| μονάς / Τριάς | Monad / Trinity | "Monad" as in the Nazianzen translations; the Trinity–Monad antithesis is a figure Sophronius repeats |
| ὁμοούσιος / τὸ ὁμοούσιον | consubstantial / consubstantiality | the creed's word; "coessential" rejected as unidiomatic though it would match "essence" — the one οὐσία-root rendered off-stem |
| ἐνέργεια | operation | the controversy's term: "two operations"; never "energy" or "activity"; ἐνεργεῖν = operate, ἐνεργητικός = operative, ἐνέργημα = effect of operation |
| θέλημα | will | "one will / two wills" |
| θέλησις | volition | the faculty as distinct from its object (Maximus will need the pair; keep them apart from the start); θέλειν = to will |
| θεανδρικὴ ἐνέργεια | theandric operation | Dionysius's word, left Greek-English; T note once with the source (Ep. 4) |
| ἰδιότης | property | the natural properties; ἰδίωμα = idiom (a single characteristic mark); never merge the two |
| ἕνωσις | union | ἑνοῦν = unite; καθ᾿ ὑπόστασιν ἕνωσις = hypostatic union; συνάφεια = conjunction (Nestorius's word, pejorative here) |
| σύγχυσις / ἀσύγχυτος / ἀσυγχύτως | confusion / unconfused / without confusion | |
| τροπή / ἄτρεπτος / ἀτρέπτως | change / unchangeable / without change | ἀναλλοίωτος = unalterable |
| διαίρεσις / ἀδιαίρετος / ἀδιαιρέτως | division / undivided / without division | Chalcedon's four adverbs: without confusion, without change, without division, without separation |
| χωρισμός / ἀχώριστος / ἀχωρίστως | separation / inseparable / without separation | |
| μερισμός / μεριστός / ἀμέριστος | partition / partible / impartible | kept apart from διαίρεσις — Sophronius uses both in one sentence (anchor § 2) |
| τμῆσις / διατέμνειν | cutting / cut asunder | |
| σύνθεσις / σύνθετος | composition / composite | "composite hypostasis" |
| διαφορά | difference | "the natural difference" of the natures; διάφορος = different |
| ἐκ δύο φύσεων / ἐν δύο φύσεσι | from two natures / in two natures | the prepositions are the argument: never level them |
| σάρκωσις / σαρκοῦσθαι | incarnation / be incarnate | |
| ἐνανθρώπησις / ἐνανθρωπεῖν | becoming man / become man | kept distinct from σάρκωσις (Sophronius pairs them) |
| οἰκονομία | economy | the dispensation of the Incarnation; οἰκονομικός = of the economy, οἰκονομικῶς = by way of economy; never "plan" or "dispensation" |
| Λόγος | the Word | Λόγος Θεοῦ = the Word of God; λόγος (speech, reason, oration) lower case by sense |
| Θεοτόκος | Theotokos | transliterated, because Sophronius also writes Θεομήτωρ (×10 in the homilies) = Mother of God; the two must stay distinguishable; T note on first use |
| Θεομήτωρ | Mother of God | |
| Παρθένος | Virgin | capital when it is Mary; ἀειπάρθενος = ever-virgin; παρθενία = virginity |
| θεοδόχος | God-receiving | κυοφορία = child-bearing, κυοφορεῖν = bear in the womb |
| Δεσπότης | Master | capital for Christ (ὁ Δεσπότης, Δέσποτα); lower-case "master" in the Letter's address to Sergius; δεσποτεία = lordship (the Trinity's) |
| Κύριος | Lord | κυριότης = lordship |
| Σωτήρ | Saviour | σωτηρία = salvation; σωτήριος = saving |
| πάθος / παθήματα | passion / sufferings | Christ's πάθος = passion; πάθη of the soul = passions |
| θαύματα | miracles | θαυματουργεῖν = work miracles |
| θεοπρεπής / ἀνθρωποπρεπής | befitting God / befitting man | the Letter's test for which operation belongs to which nature |
| αὐτεξούσιος | self-determining | γνώμη = judgement, γνωμικός = of judgement (Maximus later) |
| κοινωνία | communion | the Letter's closing demand for communion |

**Heresiarchs and fathers in their standard English forms** (one form each, whatever the Greek prints —
Ἀπολλινάριος and Ἀπολινάριος both occur): Simon (Magus), Cerinthus, Ebion, Basilides, Marcion (Marcionites),
Montanus, Noetus, Sabellius (Sabellians), Paul of Samosata, Manes, Arius (Arians), Aetius, Eunomius, Eudoxius,
Macedonius, Apollinarius (Apollinarians), Origen, Didymus, Evagrius, Nestorius (Nestorians), Theodore (of
Mopsuestia), Theodoret, Eutyches (Eutychians), Dioscorus, Timothy (Aelurus), Peter (Mongus / the Fuller — as
the Greek distinguishes), Severus, Julian (of Halicarnassus), Themistius, Theodosius, Anthimus, Jacob
(Baradaeus — the Jacobites' founder), Meletius; the Nicolaitans. Fathers: Cyril, Leo, Athanasius, Basil,
Gregory. Emperors: Justinian. **Where a name's bearer is ambiguous (two Peters, two Theodosii, two Julians), a
one-line P note, never an expansion in the text.**
